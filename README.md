## Program 7 – Inheritance (Car and Bike)

### Aim
To demonstrate inheritance in Python by creating a base class `car` and a derived class `bike`.

### Algorithm
1. Start the program.
2. Create a class named `car`.
3. Define a method `BMW()` inside the `car` class to display "BMW".
4. Create a derived class named `bike` that inherits from `car`.
5. Define a method `RE()` inside the `bike` class to display "RE".
6. Create an object of the `bike` class.
7. Call the `BMW()` and `RE()` methods using the object.
8. Stop the program.

## Program 7.2 – Method Overriding Using Inheritance

### Aim
To demonstrate method overriding and the use of the `super()` function in Python inheritance.

### Algorithm
1. Start the program.
2. Create a base class named `base`.
3. Define a method `method()` in the base class to display a statement.
4. Create a derived class named `derived` that inherits from `base`.
5. Define the `method()` inside the derived class.
6. Use `super()` to call the method of the base class.
7. Display a statement from the derived class.
8. Create an object of the derived class.
9. Call the method to display statements from both classes.
10. Stop the program.
